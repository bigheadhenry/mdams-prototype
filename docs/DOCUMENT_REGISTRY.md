## 状态标签说明

| 标签 | 含义 |
|------|------|
| 当前事实入口 | 与稳定实现对齐，可做开发/部署/验收依据 |
| 专题说明 | 围绕某个子系统的补充说明 |
| 研究材料 | 服务论文/研究论证，不替代工程文档 |
| 实施方案 | 阶段计划/路线图，不可当作已实现事实 |
| 历史 | 已迁移或过时，仅供追溯 |
| 应急记录 | 特殊环境下的排障或操作记录 |
| **新增** | 本次更新新增的文件 |

## 更新规则

1. 新增功能/模块 → 更新相应当前事实入口 + CHANGELOG + VERSION
2. 修复/优化 → 更新 WORK_LOG + 可能需更新文档
3. API/配置变更 → 更新 API_ROUTE_MAP / ENVIRONMENT_VARIABLES / 平台来源文档
4. 角色/权限变更 → 更新 USER_ROLE_PERMISSION_MATRIX + 菜单矩阵
5. 部署变更 → 更新 SETUP_AND_DEPLOYMENT + TROUBLESHOOTING
6. 每次变更后 → 同步更新本注册表的「最后更新」日期
