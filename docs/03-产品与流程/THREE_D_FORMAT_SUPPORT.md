# 三维模型格式支持说明

本文说明当前 MDAMS 原型中三维模型的上传、保存与在线预览边界。

## 结论

当前系统可以上传并保存多种三维模型格式，但在线 Web 预览只稳定支持 `GLB` 和 `glTF`。

推荐使用顺序：

1. `GLB`：首选在线预览格式。单文件，通常包含模型、材质与贴图，最适合直接上传后在浏览器中查看。
2. `glTF`：可在线预览，但通常依赖同目录下的 `.bin` 和贴图文件，上传与保存时需要保持完整文件组。
3. `OBJ`、`FBX`、`STL`、`USDZ`：当前可作为三维模型文件上传、保存、下载和打包导出，但暂不作为在线 Web 预览格式。

## 当前实现边界

上传入口接受以下三维模型文件：

- `.glb`
- `.gltf`
- `.obj`
- `.fbx`
- `.stl`
- `.usdz`

前端三维预览器当前使用 Three.js 的 `GLTFLoader`，因此浏览器内直接渲染的格式范围是：

- `.glb`
- `.gltf`

其他格式没有接入对应 loader，例如 `OBJLoader`、`FBXLoader`、`STLLoader` 或 USDZ 相关预览链路。因此这些格式虽然会被系统保存为模型文件，但当前不应承诺可直接在线预览。

## 操作建议

从 Sketchfab 或其他来源下载模型时：

- 如果目标是立即在 MDAMS 里预览，优先下载 `GLB`。
- 如果只提供 `glTF`，需要连同 `.bin` 和贴图等依赖文件一起保存。
- 如果需要长期保存或后续转换，可以同时保留 `OBJ`、`FBX`、`STL`、`USDZ` 等源格式。
- 如果当前只有 `OBJ`、`FBX`、`STL` 或 `USDZ`，建议先用 Blender 等工具转换为 `GLB`，再作为 Web 展示版本上传。

## 后续扩展

如需让更多格式直接在线预览，可在前端三维预览器中按格式接入对应 Three.js loader，并在后端 viewer summary 中增加格式级别的预览能力判断。当前原型先把归档保存能力和 Web 预览能力明确区分，避免用户误以为所有已上传模型都能直接渲染。
