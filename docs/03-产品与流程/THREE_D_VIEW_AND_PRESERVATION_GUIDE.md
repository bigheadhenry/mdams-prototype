# 三维浏览与保存说明

- 最后核对日期：2026-05-23
- 文档状态：current
- 核对口径：以当前三维管理、统一平台三维来源、Web 预览和保存状态字段为准
- 相关文档：`THREE_D_OBJECT_MODEL_AND_PLATFORM_VIEW.md`、`THREE_D_FORMAT_SUPPORT.md`

## 1. 目标

本文件用于把“三维可浏览能力”和“三维保存能力”明确分开。当前系统已经可以上传、保存、分组展示和在线预览部分三维资源，但并不是所有已保存的三维文件都能直接在浏览器中稳定渲染。

## 2. 当前三维链路

当前三维链路由四层组成：

```text
藏品对象
  -> 三维数字对象
      -> 模型表现 / 资源包
          -> 文件
```

当前数据库层仍以 `ThreeDAsset` 表承载模型表现和资源包语义；统一平台和前端管理页已经按 `collection_object_id + resource_group` 聚合为三维数字对象视图。

## 3. 在线浏览能力

当前在线浏览优先支持：

- `GLB`
- `glTF`，包括其依赖的 `.bin` 和贴图

当前系统会把对象级 `preview_enabled` 理解为：

> 该三维数字对象下存在一个可作为默认 Web 展示的模型表现。

它不是说对象下所有模型表现都能在线预览。

## 4. 保存能力

保存能力覆盖范围更宽。当前可作为三维模型或相关文件保存、下载、打包和归档描述的格式包括：

- `GLB` / `glTF`
- `OBJ`
- `FBX`
- `STL`
- `USDZ`
- 点云、贴图、倾斜摄影、采集报告、处理报告、质检说明等辅助文件

保存状态字段当前主要用于表达资源包级别的保存阶段：

| 字段 | 含义 |
| :--- | :--- |
| `storage_tier` | 保存层，如 archive / access / derivative |
| `preservation_status` | 保存状态，如 pending / preserved / needs_review |
| `preservation_note` | 保存说明 |

## 5. 推荐三维资源组织

同一三维数字对象下，建议至少区分两类模型表现：

| 表现类型 | 用途 | Web 预览 |
| :--- | :--- | :--- |
| 原始保存级 | 保留采集和处理成果，服务长期保存和复核 | 通常不直接预览 |
| Web 展示级 | 浏览器展示、汇报演示、普通利用 | 应优先使用 GLB |

如果有研究需求，可继续增加：

- 高精度研究级
- 移动轻量级
- 其他派生级

## 6. 上传与预览建议

推荐操作方式：

1. 原始包按原始结构保存，文件角色标为 `model`、`point_cloud`、`texture`、`support` 等。
2. 另行准备一个 Web 展示级 `GLB` 或完整 `glTF` 文件组。
3. 将 Web 展示级标记为可预览表现。
4. 在统一平台中以三维数字对象为主项展示，而不是平铺所有文件。

如果当前只有 `OBJ`、`FBX`、`STL` 或 `USDZ`，建议先用 Blender 或生产工具转换出 `GLB`，再作为 Web 展示表现上传。

## 7. 统一平台中的三维展示

统一平台当前以三维数字对象作为默认粒度：

- 列表项代表一个三维数字对象。
- 详情页展示该对象下的模型表现列表。
- 默认预览选择可 Web 展示的表现。
- 下载动作应优先指向表现级资源包，而不是混合所有对象文件。

## 8. 当前边界

当前不应承诺：

- 所有三维格式均可在线浏览。
- 所有三维对象均有 Web 展示级文件。
- 已上传文件自动完成格式转换。
- 已保存资源已经满足完整长期保存系统要求。

当前可以承诺：

- 三维资源包可以按角色保存。
- 三维对象可以在管理页和统一平台按对象级聚合展示。
- 有 GLB / glTF Web 展示表现时，可以进入在线预览链路。
- 保存状态、文件角色和生产记录已经有最小表达。
