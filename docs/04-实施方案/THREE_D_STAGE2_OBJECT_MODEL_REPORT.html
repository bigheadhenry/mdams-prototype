接口与界面变化

  • 新增 GET /api/three-d/digital-objects 对象目录接口。
  • 上传、列表、详情、元数据字典和统一平台记录均输出对象 ID、表示类型和发布状态。
  • 资源列表支持按表示类型过滤，PATCH 支持受控修改表示类型。
  • 入库向导增加表示类型选择；管理页按数字对象聚合，目录优先展示显式表示类型。
