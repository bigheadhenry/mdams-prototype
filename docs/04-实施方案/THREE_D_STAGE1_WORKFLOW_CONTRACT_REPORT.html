冻结的表现类型

original_master

原始保存级；禁止直接公开展示。

web_display

标准 Web 展示级表现。

mobile_lightweight

移动端与低带宽轻量表现。

高精度研究用途表现。

其他受控派生表现。

发布状态机

draft
→
validating
→
approved
→
published
→
withdrawn

分支： validating 可进入 rejected；withdrawn 与 rejected 只能回到 draft，禁止跳过审批直接发布。

核心契约

最小登记必须提供标题、对象分组、表现类型、版本标签和存储层级。
最小展示必须 ready、已发布、允许 Web 展示，并包含 model 角色的 GLB 或 glTF。
当前版本唯一同一对象、同一表现类型只能存在一个 current 版本。
默认 Web 表现唯一同一三维数字对象只能有一个 ready 的默认 Web 表现。
原始保存级隔离original_master 不能发布，也不能设置为默认 Web 表现。
显式类型representation_type 必须明确记录，不允许继续由 version_label 猜测。
